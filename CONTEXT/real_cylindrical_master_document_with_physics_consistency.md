# real cylindrical master document.md
## 项目名称
Real Cylindrical Physics-Guided Learned 3D Imaging

## 文档角色
本文件是**新项目的唯一上位主控文档**。  
它服务于一个**从头开始重建**的柱面孔径 3D 学习成像论文项目。

本项目**不继承旧版二维代理 ET 数据集的实验结论**，也**不再围绕旧版错误几何设定做补丁式延续**。  
本项目的基本立场是：

> **从真正的柱面物理仿真重新出发，构建“参考面近似物理骨干 + Manisali 风格 3D U-Net second-stage”的两阶段学习成像框架，验证其是否能在点目标与 extended target 尤其是后者上，推动传统快速算法的速度–质量边界。**

---

# 1. 论文目标与问题定义

## 1.1 论文核心问题

本论文关注的问题不是一般意义上的“图像增强”，也不是单纯地让深度网络拟合 BP 输出。  
本论文要回答的是：

> **在真正柱面孔径物理仿真下，物理指导学习成像是否能够在保持快速参考面近似算法低复杂度优势的同时，显著提升成像质量，从而推动传统快速算法的速度–质量边界。**

也就是说，本文的主问题是：

- 传统柱面快速参考面算法虽然快，但成像质量受参考面数量限制；
- 参考面数量越少，近似误差越大；
- 参考面数量越多，质量越好，但复杂度上升；
- 学习成像是否可以在**低参考面物理骨干**之上，学习近似误差补偿，使结果逼近更高质量成像，同时保留速度优势。

## 1.2 论文立场

本文明确采用以下立场：

1. **物理骨干优先，而非纯黑盒重建**  
   本文不从 raw echo 直接端到端回归 3D 图像作为主线，而是采用物理前端 + 学习精化的两阶段路线。

2. **真正柱面物理仿真优先，而非二维代理数据集**  
   本文不再使用旧版二维 family 代理生成逻辑作为主证据来源，而是从真正柱面几何、真正前向回波、真正 `ref3/ref5/ref7/ref9/BP` 重建链路出发。

3. **extended target 是主战场，点目标是前置验证**  
   点目标实验用于：
   - 验证柱面物理仿真链路是否正确；
   - 验证参考面数量变化对误差与速度的影响是否符合物理预期；
   - 验证学习成像在最简单场景中的可行性。  
   但论文的主结论必须落在 extended target 上。

4. **幅度重建为主**  
   当前项目阶段，学习目标定义为**幅度重建**，而非复数重建。主指标也围绕幅度图像质量与速度展开。

# 2. 方法总框架

## 2.1 总体框架

本文采用如下两阶段框架：

### 第一阶段：参考面近似物理骨干
在真正柱面孔径仿真数据上，使用低参考面数量的参考面近似成像算法作为物理骨干，例如：

- `ref3` reduced-reference backbone

该骨干负责：

- 将原始柱面回波映射到粗粒度 3D 重建体；
- 提供具有物理意义的 warm start；
- 保留快速算法的低复杂度优势。

### 第二阶段：Manisali 风格 3D U-Net second-stage
以第一阶段的粗重建体作为输入，使用 **3D U-Net denoiser / refiner** 做幅度重建精化，输出高质量 3D 幅度体。

其角色是：

- 学习参考面近似误差补偿；
- 恢复高质量结构；
- 改善低参考面近似带来的失焦、模糊与细节损失。

## 2.2 为什么采用该框架

该框架的优势在于：

1. **保留柱面物理可解释性**  
   网络不是在完全无约束地“凭空想象”，而是在物理骨干输出的基础上做 refinement。

2. **与近场 MIMO 学习重建文献对齐**  
   Manisali 路线的核心启发是：
   - 先给网络一个物理 warm start；
   - 再用 3D U-Net 学习 object-space refinement。  
   本项目采用相同的大范式，但把平面近场 MIMO 的物理前端替换为**真正柱面参考面近似骨干**。

3. **适合回答速度–质量边界问题**  
   若最终结果优于 `ref3` 并部分逼近 `ref5/ref7/ref9/BP`，同时 runtime 仍接近 `ref3`，则这条路线就成立。

# 3. 数据集总设计

本项目的训练数据不再是一类单一数据，而是明确分成三类。  
三类数据的角色不同，不可混淆。

## 3.1 数据集一：稀疏随机点目标数据集

### 角色
点目标数据集不是主战场，而是**前置物理验证数据集**。

### 作用
1. 验证柱面前向仿真链路是否正确；
2. 验证 `ref3/ref5/ref7/ref9/BP` 的质量–复杂度变化趋势；
3. 验证学习成像在最简场景中是否能够完成从粗图到高质量图的映射；
4. 验证当目标位于不同半径 / 距离向 / 高度 / 方位位置时，近似误差如何变化。

### 规模要求
- 训练集至少 **5000+**
- 验证集、测试集规模也必须充足，不能再维持过小样本数

### 场景要素
点目标数据集必须覆盖：
- 不同半径位置
- 不同高度位置
- 不同方位位置
- 单点
- 双点
- 少量多点
- 不同散射强度
- 不同相对距离

### 注意
点目标数据集的职责不是证明最终论文价值，而是保证：
- 物理仿真正确；
- 几何误差机制被真实反映；
- 学习链路基础可行。

---

## 3.2 数据集二：extended target 特定 shape family 数据集

### 角色
这是论文的**主训练集 / 主验证集 / 主战场**。

### family 集合
至少覆盖以下类型：

- `line`
- `cross`
- `L-shape`
- `double-line`
- `small_rect_edge`
- `point_cluster`

如后续物理仿真链路允许，可进一步扩展，但上述 family 必须优先保留。

### 作用
1. 检验算法在可解释的结构场景下的表现；
2. 检验 thin-support、edge-like、connected-support 等结构难点；
3. 构成论文主图主表的基础。

### 规模要求
每类 family 训练样本至少 **5000+**。  
即如果 family 为 6 类，则总训练样本规模将远高于 5000。  
是否完全等量，由 protocol 文件进一步冻结；但总原则是：

- family 数量不能太小；
- hard family 覆盖必须充分；
- 参数空间覆盖必须明确记录。

### 参数多样性要求
每一类 family 都必须显式覆盖：
- 尺寸
- 方向
- 位置
- 边界接近程度
- 厚度 / 宽度
- 间距 / 缺口 / 断裂
- 强度变化
- 多实例组合方式

不得只做“图样模板复制”。

---

## 3.3 数据集三：Manisali 风格随机 extended target 数据集

### 角色
这是**补充性训练/泛化数据集**，用于提供更宽的 target 分布覆盖。

### 作用
1. 防止模型只记住 hand-crafted family；
2. 检查模型对随机分布 extended targets 的泛化能力；
3. 与 family 数据集形成互补。

### 生成思路
借鉴 Manisali：
- 随机目标中心
- 局部虚拟中心
- 随机点簇
- 3D smoothing / volumetric aggregation
- 得到随机分布式 3D extended targets

但必须放入**真正柱面物理仿真链路**中，而不是直接做二维图像代理生成。

### 规模要求
训练样本至少 **5000+**。

### 在论文中的位置
Manisali-style 随机数据集不是主 benchmark，而是：
- 训练补充来源
- 泛化补充验证来源  
论文主结论仍必须依托 shape-family ET 集。

# 14. 物理一致性损失函数：项目中的定位与实施规划

## 14.1 为什么要引入物理一致性

本文的“物理指导”不只体现在第一阶段的参考面近似物理骨干嵌入，还体现在：

> **第二阶段输出的成像结果，原则上应能够通过前向物理模型重新生成回波，并与原始回波保持一致。**

这类思想在学习重建领域通常可归入：
- physics consistency
- data consistency
- forward consistency
- measurement fidelity

其基本形式是：

1. 网络输出一个预测 3D 图像体 `x_hat`
2. 将 `x_hat` 送入可微或近似可微的前向算子 `F(·)`
3. 得到预测回波 `y_hat = F(x_hat)`
4. 将 `y_hat` 与真实回波 `y` 做误差约束

其作用不是替代主监督，而是：

- 防止网络仅在图像域“看起来像”正确图像；
- 迫使输出仍然解释原始测量；
- 提高物理可解释性与跨域稳健性。

## 14.2 本项目对物理一致性的基本立场

本项目明确采用以下立场：

1. **物理一致性是本论文的重要增强方向，但不是起步阶段的首要阻塞项。**
2. **必须先完成“参考面近似物理骨干 + Manisali 风格 3D U-Net second-stage”的主基线。**
3. **只有在两阶段主基线跑通、速度–质量基线清楚之后，才正式引入物理一致性损失。**

这样安排的理由是：

- 柱面物理仿真链路本身已经复杂；
- 3D U-Net second-stage 的结构与训练稳定性需要先确认；
- 物理一致性会引入额外的 forward pass 计算开销；
- 若一开始同时引入新几何、新数据、新网络和 forward consistency，系统过重，难以归因。

因此：

> **物理一致性在本项目中被定义为“第二阶段增强项”，而不是 Phase 1 的必要条件。**

## 14.3 物理一致性的目标不是替代主监督

本项目中，主监督仍保持为：

> **场景真值 reflectivity / voxel truth 的幅度体监督**

物理一致性损失不替代该主监督，而作为额外正则项加入。  
也就是说，训练目标应是：

- 一部分负责图像重建质量；
- 一部分负责测量一致性。

其原则写作可表述为：

`L_total = L_image + lambda_pc * L_physics_consistency`

其中：

- `L_image`：主图像域损失（如幅度 L2 / NMSE 等）
- `L_physics_consistency`：前向回波一致性损失
- `lambda_pc`：权重系数

## 14.4 物理一致性在本项目中的推荐形式

### 推荐主形式：forward echo consistency
最符合本项目物理问题的形式是：

1. 网络输出预测 3D 幅度体 `x_hat`
2. 使用柱面前向模型 `F_cyl(·)` 生成预测回波 `y_hat`
3. 将 `y_hat` 与原始仿真回波 `y` 比较

推荐基础定义：

- `L_echo = || y_hat - y ||_2^2`
或
- 归一化版本的 echo-domain NMSE

### 允许的轻量近似
由于完整柱面 forward 计算可能昂贵，本项目允许在增强阶段考虑：

- sampled echo consistency
- sub-aperture consistency
- partial-frequency consistency
- mini-batch ray / angle / height subset consistency

即：
不一定每一步都对完整全孔径、全频率回波计算一致性，也可以对采样后的测量子集计算一致性，以控制训练开销。

## 14.5 物理一致性与参考面物理骨干的关系

本文必须强调：

- 第一阶段的 `ref3` 物理骨干，已经在“输入侧”嵌入了物理；
- 第二阶段加入物理一致性损失，则是在“输出侧”补上物理约束。

因此，本项目的“物理指导”有两个层次：

### 层次一：physics-embedded backbone
- 参考面近似算法作为 coarse reconstruction warm start

### 层次二：physics-consistent training
- 网络输出通过前向物理模型约束回到测量空间

这两层结合，才能构成更完整的 physics-guided / physics-consistent learned imaging 叙事。

## 14.6 何时引入物理一致性

本项目规定如下顺序：

### 先完成
1. 真正柱面物理仿真链路
2. 点目标前置验证
3. shape-family ET 主数据集
4. Manisali 风格随机 ET 数据集
5. `RED_ref3 + 3D U-Net` 两阶段基线
6. 与 `ref3/ref5/ref7/ref9/BP` 的主指标对比

### 再引入
7. 物理一致性损失版本
8. 比较：
   - 无 physics consistency 的两阶段基线
   - 有 physics consistency 的增强版本

## 14.7 物理一致性实验的目的

物理一致性增强实验的目标不是简单追求更低图像域误差，而是回答：

1. 在保持 runtime 可接受的前提下，forward consistency 是否能提升图像质量？
2. 它是否能改善 thin / edge / connected-support 场景中的结构恢复？
3. 它是否能提高模型对不同半径位置、不同 target 分布的稳健性？
4. 它是否能在后续真实数据后置验证中提供更强的物理可信度？

## 14.8 物理一致性在论文中的预期位置

在论文结构中，物理一致性建议放在：

- **主方法跑通之后的增强实验**
- 或主方法章节中的“physics-consistent extension”小节
- 或后半部分的进阶版本/增强版本实验

不建议把它写成必须与基线主方法同时成立的前提。  
原因是：
本论文首先要证明的是：

> **参考面近似物理骨干 + second-stage 3D U-Net 本身是否成立。**

在此之上，再证明：

> **加入物理一致性损失后，是否能进一步增强物理可信度和结构恢复。**

## 14.9 项目中的最终定位

因此，本 master document 将物理一致性规划正式定义为：

> **本项目的明确后续增强方向，属于“物理指导”叙事的第二层：physics-consistent training。**
>
> 它将在“参考面近似物理骨干 + Manisali 风格 3D U-Net second-stage”基线完成后正式引入，并以前向回波一致性损失为首选实现形式。
