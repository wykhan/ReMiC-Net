# reference_surface_strategy.md
## 文件角色
本文件用于**正式冻结新项目中参考柱面（reference cylindrical surfaces）的选择策略**。

它回答以下问题：

1. 完整参考柱面库是什么；
2. `ref3 / ref5 / ref7 / ref9` 分别选哪些参考柱面；
3. `ref3` 与 `ref3` 的关系是什么；
4. 后续点目标、extended target、学习骨干、传统基线必须如何统一使用这些参考柱面。

本文件与 `simulation_protocol.md` 配套使用：

- `simulation_protocol.md` 冻结真正柱面几何、采样参数、完整参考柱面库；
- `reference_surface_strategy.md` 冻结从完整参考柱面库到 `ref3/ref5/ref7/ref9` 的抽样规则。

# 1. 生成依据与立场

## 1.1 理论依据
谭维贤论文明确指出：
- 成像区域被划分为**不同半径的成像柱面**；
- 需要依据**成像精度和相位误差控制范围**设置参考柱面；
- 文中给出了“参考面最佳分配策略”和复杂度分析。fileciteturn39file6

同时，柱面孔径相关梳理报告也明确指出：
- 参考面近似方法的核心 trade-off 是**计算效率**与**远离参考面的失焦/几何失配误差**之间的权衡；
- 目标离参考面越远，几何失配越强，聚焦质量越差。fileciteturn39file13

## 1.2 实现依据
当前可见的谭维贤对应 MATLAB 代码 `points_4_202406.txt` 已经冻结了：
- 扫描半径 `R = 0.6 m`
- 场景半径 `X0 = 0.3 m`
- 完整参考柱面库 `rho_ref = 0:0.01:X0`
- 即完整参考柱面半径集合为 `0.00, 0.01, ..., 0.30 m`。fileciteturn39file8

## 1.3 当前文件的定位
当前资料能够明确支持：
- “完整参考柱面库”的定义；
- “参考柱面越少越快、但误差越大”的物理逻辑；
- `ref3` 在历史项目中就是 bare reduced-ref3 physical backbone。fileciteturn39file2

但在当前可见片段中，**并没有直接给出一个已经写死的 `ref3 / ref5 / ref7 / ref9` 具体索引表**。  
因此，本文件的作用是：

> **在谭维贤几何与代码冻结参数的基础上，为新项目正式定义一个唯一、确定、可复现的参考柱面抽样策略。**

这是一份**项目级协议冻结**，不是对旧项目隐含策略的盲猜。

# 2. 完整参考柱面库（full reference-surface library）

## 2.1 定义
完整参考柱面库定义为：

`rho_ref_full = {0.00, 0.01, 0.02, ..., 0.30} m`

其中：
- 最小参考半径：`0.00 m`
- 最大参考半径：`0.30 m`
- 参考半径间隔：`0.01 m`
- 总数量：`31`

这与 `points_4_202406.txt` 中的：

`rho_ref = 0 : 0.01 : X0,  X0 = 0.3`

完全一致。fileciteturn39file8

## 2.2 物理含义
这里的 `rho_ref` 代表：
- 成像区域在柱坐标下按半径方向划分后的参考柱面半径；
- 不是天线轨道半径；
- 不是目标实际半径；
- 而是匹配滤波/聚焦时使用的**参考近似半径层**。

# 3. 新项目冻结的总体原则

新项目中，`ref3 / ref5 / ref7 / ref9` 的定义必须遵循以下原则：

## 3.1 原则一：所有 reduced-reference 版本都必须从同一个完整参考柱面库中抽样
不得：
- 自行为不同实验构造不同的 `rho_ref` 总库；
- 让 `ref3` 与 `ref5` 来自不同的底层参考半径集合；
- 对不同数据集使用不同版本的参考柱面库而不记录。

## 3.2 原则二：抽样必须是确定性的、可复现的
不得：
- 手工临时改动；
- 根据单次实验结果事后挑选；
- 在不同脚本里使用不同索引。

## 3.3 原则三：必须覆盖 radial range 的两端
每个 reduced-reference 集合都必须包含：
- `0.00 m`
- `0.30 m`

理由：
- 中心区域与外缘区域都必须被约束；
- 若不包含两端，容易在外缘或中心形成额外系统性误差。

## 3.4 原则四：在当前 v1 中，默认采用**径向均匀抽样**
在没有更高等级、经正式验证的新策略之前，项目统一采用：

> **在完整参考柱面库上做“含两端点的径向均匀抽样”。**

原因：
1. 与 `rho_ref = 0:0.01:0.30` 的实现最自然一致；
2. 最容易解释与复现；
3. 不引入额外经验主义偏置；
4. 适合作为论文主线的 first-principles baseline。

## 3.5 原则五：后续若引入 phase-error-aware 非均匀策略，必须新开版本号
也就是说：
- 当前文件冻结的是 `reference_surface_strategy_v1`
- 如果未来想按相位误差密度在外缘更密采样，必须新开 `v2`
- 不允许 silently 替换当前 v1

# 4. 统一抽样算法（protocol v1）

## 4.1 抽样规则
给定：
- 完整参考柱面库长度 `L = 31`
- 目标参考面数量 `N ∈ {3,5,7,9}`

定义离散索引集合：

`idx(N) = round(linspace(0, L-1, N))`

其中：
- `linspace(0, 30, N)` 生成从 0 到 30 的等间距位置；
- `round` 将其映射到最近的可用离散参考柱面索引；
- 实际取值再对应到 `rho_ref_full[idx + 1]`

## 4.2 为什么采用这个规则
该规则满足：
- 两端点必保留；
- 中心附近自动保留；
- 在径向上尽可能均匀；
- 完全确定、无主观性；
- 对 `N=3/5/7/9` 都能生成单值结果。

## 4.3 索引记法说明
本文件同时给出：
- **0-based 索引**：对应数学表达和 `linspace(0,30,N)`
- **半径值**：最终真正使用的 `rho_ref` 值

在代码实现时，可根据语言改为 1-based 数组索引，但**半径值定义不变**。

# 7. 参考柱面与体素/目标半径的匹配规则

新项目中的每个体素或目标点，其真实半径为 `rho_target`。  
在 reduced-reference 成像中，应使用如下原则：

## 7.1 最近参考柱面原则
每个目标半径 `rho_target` 由其最近的参考柱面 `rho_ref_selected` 负责聚焦/近似。

即：

`rho_ref_selected = argmin_{rho_ref in selected_set} |rho_target - rho_ref|`

## 7.2 含义
这意味着 reduced-reference 误差来自：

- `rho_target` 与最近 `rho_ref` 之间的径向失配；
- 该失配越大，近似误差一般越强；
- 这正是学习补偿需要处理的结构化误差来源之一。

## 7.3 后续分析要求
在新项目中，点目标 controlled validation 必须显式分析：

- 当 `rho_target` 位于不同径向位置时，
- 对应 `ref3/ref5/ref7/ref9` 的误差如何变化。

# 8. 该策略在点目标与 extended target 中的使用方式

## 8.1 点目标
点目标实验中：
- 直接使用本文件冻结的 `ref3/ref5/ref7/ref9`
- 显式研究：
  - 单点位于不同 `rho_target`
  - 双点/少点位于不同 `rho_target`
  - reduced-reference mismatch 对图像质量的影响

## 8.2 extended target
extended target 中：
- 同一目标内部不同体素半径不同；
- 因此一个 extended target 往往横跨多个参考柱面分区；
- 这恰恰是学习补偿要面对的更真实、更困难的情况。

因此：
- `shape-family ET`
- `Manisali-style random ET`

都必须使用**同一套** `ref3/ref5/ref7/ref9` 策略，不得另开私有版本。

---

# 9. 为什么当前 v1 不采用“边缘更密、中间更稀”的非均匀策略

这是一个可能的未来升级方向，但当前 v1 不采用，理由如下：

1. 当前最重要的是建立**无歧义基线**；
2. 新项目刚刚从旧几何偏差中重启，优先级是“正确”和“可追溯”，不是“经验优化”；
3. 非均匀策略若要成立，必须有明确的：
   - 相位误差推导
   - 径向误差统计
   - 点目标 controlled validation 支撑；
4. 在这些证据完成前，均匀径向抽样更适合作为主线协议。

# 10. v1 策略的局限与升级条件

## 10.1 局限
当前 v1 的局限在于：
- 它保证可复现与覆盖均匀；
- 但不保证对外缘失配做最优加权；
- 也不保证是“谭维贤文中最佳分配策略”的唯一精确离散实现。

## 10.2 升级条件
只有当完成以下工作后，才允许提出 `reference_surface_strategy_v2`：

1. 点目标不同半径位置的误差曲线已系统建立；
2. 明确发现某些径向区域误差对最终图像主导更强；
3. 非均匀参考柱面布置在主指标上显著优于当前 v1；
4. 该策略不会破坏传统曲线与学习骨干定义的统一性。
