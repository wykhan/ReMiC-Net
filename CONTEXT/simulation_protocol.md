# 2. 坐标系与几何定义

## 2.1 坐标系
采用柱面扫描几何，对目标和天线同时使用笛卡尔坐标与柱坐标描述。

### 天线阵元位置
- 笛卡尔坐标：`T(x', y', z')`
- 柱坐标：`T(ρ', θ', z')`

### 场景目标点
- 笛卡尔坐标：`P(x, y, z)`
- 柱坐标：`P(ρ, θ, z)`

## 2.2 扫描结构
采用**柱面扫描**：
- 方位向：天线围绕 `Z` 轴做圆周扫描
- 高度向：垂直方向设置线阵/等效采样
- 距离向：通过频率扫描形成

## 2.3 当前 protocol v1 的几何主参数（冻结）
以下参数直接来自 `points_4_202406.txt`，作为 protocol v1 固定值：

- 方位向有效观测角：`theta_u = 30.0°`
- 高度向有效观测角：`theta_h = 30.0°`

说明：
- `R = 0.6 m` 表示扫描轨道半径；

# 3. 信号模型

## 3.1 单目标回波模型
采用谭维贤论文中的柱面孔径单点目标模型：

`s(Kω, θ', z') = I(ρ, θ, z) * exp(-j 2 Kω R)`

其中：
- `I(ρ, θ, z)` 为目标散射系数；
- `Kω` 为波数；
- `R` 为天线阵元到目标点的距离。

## 3.2 距离表达式
目标点与天线阵元之间的距离为：

`R = sqrt(ρ'^2 + ρ^2 - 2ρ'ρ cos(θ - θ') + (z - z')^2)`

该表达式是柱面近场球面波路径长度的核心。

## 3.3 扩展目标回波模型
对扩展目标，采用体积分叠加：

`S(Kω, θ', z') = ∭ I(ρ, θ, z) exp(-j 2 Kω R) dv`

这也是新项目必须遵循的 forward simulation 物理基础。

## 3.4 当前代码中的实现口径
在 `points_4_202406.txt` 中，回波是通过对每个散射点叠加实现的，核心代码逻辑为：
- 对每个目标点 `(x, y, z)`：
  - 计算其到各高度采样、各方位采样位置的距离 `rn`
  - 在所有频率 `Kw` 上生成 `exp(-1j * Kw * Rn)` 型回波
  - 将各点目标回波相加得到总回波

注意：
- 当前 `Kw = 4π f / C`，对应双程传播的波数定义；
- 因此代码中的相位形式与论文的双程传播写法保持一致。

## 5.2 波数定义

## 5.3 距离向采样
代码冻结为：

- 距离向采样点数：`Nr = 181`
- 波数均匀采样：`Kw = linspace(kmin, kmax, Nr)`

## 5.4 距离向分辨率

# 6. 高度向参数冻结

## 6.1 高度采样间隔
当前代码冻结：

- `dh = 0.004000 m`（即 4 mm）

该值与论文给出的采样准则一致方向：
- 高度向采样必须满足 Nyquist 条件；
- 代码中直接采用 4 mm 作为实现值。

## 6.2 高度范围
代码定义：

- `h = -H/2 : dh : H/2`

因此当前高度范围为：

- `z ∈ [-1.0, 1.0] m`

## 6.3 高度采样点数
- `Nh = 501`

## 6.4 高度向波数
代码冻结：

- `dKz = 2π / (Nh * dh)`
- `Kz = dKz * (-Nh/2 : Nh/2-1)`

这意味着后续在高程向会进入频域处理。

## 6.5 高度有效照射限制
对单个散射点，代码使用：

`h_index = find(abs(z - h) <= (R - r) * tan(theta_h/2))`

这表示目标点只有在满足柱面几何可见性条件时才对对应高度采样位置产生贡献。

该条件必须保留到新项目真实 3D 仿真中，不得省略。

# 9. 成像主流程（当前代码实现口径）

基于 `points_4_202406.txt`，当前柱面成像流程可概括为：

1. 根据场景散射点生成回波 `s3(azimuth, range, height)`
2. 沿高度向做 Fourier 变换
3. 沿方位向做 Fourier 变换
4. 对每个高度层、每个参考柱面：
   - 构造参考匹配函数 `rn_ref`
   - 与回波在波数域相乘
   - 沿距离向积分
   - 得到 `Three_Image(azimuth, rho_ref, height)`
5. 再做高度向逆变换
6. 最后通过几何校正，从 `(azimuth, rho_ref, z)` 插值到笛卡尔 `(x, y, z)` 网格

这条流程定义了新项目中：
- 传统快速参考面算法；
- 低参考面物理骨干；
- 高参考面质量上界；
- 几何校正后 3D 体输出

的共同基础。

# 11. 谭维贤论文中的采样准则（理论冻结）

新项目在所有真正柱面 3D 仿真中，都必须满足谭维贤论文给出的采样准则思想。

## 11.1 方位向采样准则
论文通过相位函数求导得到方位向瞬时波数，再推导方位向采样间隔上界。  
原则上，新项目应保证：

- 方位向采样间隔 `Δθ'` 满足论文给出的 Nyquist 条件；
- 当前代码实现值 `du ≈ 0.3273°` 被视为 protocol v1 的冻结实现。

## 11.2 高度向采样准则
论文给出：

- `Δz' <= λ_min / [4 sin(theta_z / 2)]`

当前代码实现采用：

- `dh = 4 mm`

这被视为 protocol v1 的实际冻结值。

## 11.3 频率采样准则
论文给出：

- `Δf <= C / (4 Rmax)`

当前代码通过：
- `fmin = 30 GHz`
- `fmax = 39 GHz`
- `Nr = 181`

冻结了具体频率采样规模。  
新项目不得随意改变这些值，除非 protocol 明确升级版本。
