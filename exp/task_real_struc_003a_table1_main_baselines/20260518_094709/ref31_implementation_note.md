# ref31_implementation_note

`ref31` is the dense-reference physical baseline inside the reference-surface family. It uses the full 31-radius reference grid over 0.00-0.30 m with 0.01 m spacing. In the existing frozen comparison cache, this same 31-reference reference-surface reconstruction is stored under the historical `BP` method key. For Table 1, `T01_BP` reports the high-quality physical baseline cache and `T04_ref31` reports the same full-reference reference-surface cache explicitly as a dense-reference method, not as ground truth.
