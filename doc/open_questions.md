# open_questions

- Whether a dedicated `dataset_protocol` document should be frozen separately
- How scattering-coefficient distribution rules should be standardized across point-target and ET datasets
- Whether MIMO should be explicit in the first implementation or the current protocol v1 scope should remain the working baseline
- What granularity the first version of physics consistency should target
- How the final point-target dataset scale should be frozen
- How ET family balance and hard-case coverage should be quantified before main experiments
