# task_real_001

## Title

Project startup and governance freeze for Real Cylindrical Physics-Guided Learned 3D Imaging.

## Objective

Prepare a reproducible repository skeleton that can support later tasks under unified rules. The deliverable is a bootstrap-only project state, not a running experiment pipeline.

## Scope

- Identify `PROJECT_ROOT`
- Complete directory structure and governance files
- Register project-level context documents
- Add prompt-layer working rules and review checklist
- Add minimal scripts, including a real bootstrap self-check
- Run lightweight self-checks and write fixed report artifacts
- Initialize or organize Git state so the repository is ready for follow-up work

## Out Of Scope

- Large-scale dataset generation
- Extended-target dataset creation
- Model training
- Formal imaging benchmarks
- Silent edits to the three existing frozen `CONTEXT/` protocol documents
- Unapproved changes to geometry or sampling definitions

## Deliverables

- Repository skeleton under `PROJECT_ROOT`
- Four added `CONTEXT/` governance documents
- Three `PROMPTS/` files
- Two `doc/` files
- Four `scripts/` entry points
- Root governance files and `.gitignore`
- `exp/task_real_001_bootstrap/<timestamp>/` report artifacts

## Completion Standard

The task is complete only when bootstrap self-check passes or reaches a documented partial pass, Git state is inspected, and the repository clearly records that formal simulation and training have not started.
