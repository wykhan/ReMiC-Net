# review_checklist

Before closing a task, verify:

- The working path and `PROJECT_ROOT` were identified correctly
- `CHANGELOG_DEV.md` was updated
- `debug.md` was updated
- A script entry point exists for any executable workflow introduced by the task
- Outputs were written under `exp/` when required
- No governing protocol document was modified without explicit authorization
- The task did not cross the boundary into experiments that were out of scope
